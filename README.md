# Taskly

A polished dark-themed To-Do List mobile app built with React Native, Expo, and SQLite.

## How to run

```bash
npm install
npx expo start
```

Scan the QR code with Expo Go. Your phone and computer must be on the same Wi-Fi network, or use `npx expo start --tunnel`.
